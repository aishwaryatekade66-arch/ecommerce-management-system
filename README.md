# E-Commerce Management System

## Project Overview

This project is a simple E-Commerce Management System developed using Python and MySQL. It manages users, products, cart items, orders and order details through a database-driven application.

## Technologies Used

- Python
- MySQL
- MySQL Connector/Python

## Features

- User management
- Product management
- Product listing
- Cart management
- Order management
- Order details management
- Database connectivity using Python

## Database Structure

The project uses the following main tables:

- Users
- Products
- Cart Items
- Orders
- Order Items

## Project Files

- `ecommerce.py` – Python application code
- `ecommerce.sql` – MySQL database and table creation queries

## Learning Outcome

This project helped me practice Python, SQL, database connectivity, CRUD operations and basic E-Commerce application workflow.
